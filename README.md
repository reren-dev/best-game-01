# Ember Drift

Pilot a little ember-spirit through a dark garden at dusk. Collect light-motes to score and grow your glow; dodge thorn-shades that drift across the field; chain pickups into a combo multiplier! Every 30 seconds a "gust" wave raises speed and spawns more shades. 3 lives.

## Controls
- **Steer**: Mouse cursor / Touch / WASD / Arrow Keys
- **Dash**: Space (short cooldown, brief invulnerability)
- **Restart**: R

## Local Playtest
1. Start local server: `node serve.ts`
2. Open http://localhost:8080 in desktop Chrome.

## Validation
Run `mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts` to build and verify dossier.json and output tree.
